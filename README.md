# CodeAlpha Task Automation

A simple Python automation script developed as part of the CodeAlpha Python Programming Internship.

## What it does

The program automatically finds JPG and JPEG files in a folder and moves them into a separate folder called `JPG_Files`.

## Features

- Detects JPG and JPEG files
- Creates the destination folder automatically
- Moves image files automatically
- Leaves other file types unchanged

## Technologies Used

- Python
- os module
- shutil module
- File handling
